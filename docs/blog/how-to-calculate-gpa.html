How to Calculate GPA

Calculate GPA by dividing total grade points by total credits: GPA = Total Grade Points ÷ Total Credits

Step-by-Step Method

Step 1: Convert Letter Grades to Points

A 4.0 B- 2.7
A- 3.7 C+ 2.3
B+ 3.3 C 2.0
B 3.0 C- 1.7
D 1.0 F 0.0

Step 2: Multiply Grade Points by Credits

For each class, multiply the grade point value by the number of credit hours.

Step 3: Sum All Grade Points and Credits

Add up all the grade points and all the credit hours separately.

Step 4: Divide to Find GPA

Divide total grade points by total credits.

Example Calculation

Class 1: A (4.0) × 3 credits = 12 points

Class 2: B (3.0) × 4 credits = 12 points

Class 3: A- (3.7) × 3 credits = 11.1 points

Total: 35.1 points ÷ 10 credits = 3.51 GPA

Weighted vs Unweighted GPA

Unweighted GPA: Uses standard 4.0 scale regardless of class difficulty

Weighted GPA: Adds extra points for honors, AP, or IB classes (typically +0.5 for honors, +1.0 for AP/IB)
