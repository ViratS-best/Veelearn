Purpose:       Get specific student's quiz accuracy on assignment
Method:        GET
URL:           http://localhost:3000/api/student/{studentId}/assignment/{assignmentId}/accuracy
Auth Required: YES (Authorization: Bearer {JWT_TOKEN})

URL Parameters:
  - studentId      (required) - ID of the student
  - assignmentId   (required) - ID of the assignment

Access Control:
  ✅ Student can view own accuracy (studentId must match token user)
  ✅ Teacher/Admin can view any student's accuracy
  ❌ Student cannot view other students' accuracy

Example Requests:
  # Student viewing own accuracy
  GET /api/student/15/assignment/3/accuracy
  Authorization: Bearer STUDENT_TOKEN (user id = 15)

  # Teacher viewing student's accuracy
  GET /api/student/15/assignment/3/accuracy
  Authorization: Bearer TEACHER_TOKEN

Response Format (With Submission):

ENDPOINT (UPDATED): POST /api/student/submit-assignment
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Enhancement: Now auto-calculates quiz accuracy from user attempts

Method:        POST
URL:           http://localhost:3000/api/student/submit-assignment
Auth Required: YES (Authorization: Bearer {JWT_TOKEN})

Request Body:
{
  "assignmentId": 3,
  "completionPercentage": 85
}

Calculation Process:
  1. Gets course_id from assignment
  2. Counts total questions: SELECT COUNT(*) FROM course_questions WHERE course_id = ?
  3. Counts correct answers: SELECT COUNT(*) FROM user_quiz_attempts WHERE is_correct = TRUE
  4. Calculates accuracy: (correctCount / totalQuestions) * 100
  5. Stores in assignment_submissions table

Response Format:
{
  "success": true,
  "message": "Assignment submission recorded",
  "data": {
    "isLate": false,
    "totalQuestions": 10,
    "correctAnswers": 8,
    "quizAccuracy": 80.0
  }
}

Database Update:
  Table:     assignment_submissions
  Updated:   ✓ correct_answers = 8
             ✓ total_questions = 10
             ✓ quiz_accuracy = 80.0
             ✓ completion_percentage = 85
             ✓ is_submitted = true
             ✓ is_late = false (calculated)

Status Codes:
  200 - Success
  400 - Bad request (missing parameters)
  401 - Not authenticated
  404 - Assignment not found
  500 - Server error
