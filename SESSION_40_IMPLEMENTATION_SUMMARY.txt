================================================================================
                          HOW IT WORKS
================================================================================

LIKE WORKFLOW:
  1. User clicks 🤍 button
  2. POST /api/courses/5/like
  3. Backend inserts into course_likes table
  4. Backend increments like_count
  5. Button changes to ❤️ with pink background
  6. Count updates instantly

SORT WORKFLOW:
  1. User selects sort option
  2. GET /api/courses?sort=most_liked
  3. Backend returns courses ordered by like_count DESC
  4. Frontend re-renders course list
  5. User sees sorted results
