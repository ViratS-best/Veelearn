                              LaTeX Equation Help

                              Use LaTeX to write mathematical equations in your courses.

                              Inline Equations (in text)

                              Surround with single dollar signs: $E = mc^2$

                              Result: $E = mc^2$

                              Display Equations (on separate line)

                              Surround with double dollar signs: $$E = mc^2$$

                              Result: $$E = mc^2$$

                              Common Examples

                              • $E = hf$ → Einstein's photoelectric equation
                              • $\lambda = \frac{h}{p}$ → de Broglie wavelength
                              • $\Delta x \cdot \Delta p \geq \frac{h}{4\pi}$ → Uncertainty principle
                              • $$\int_0^\infty e^{-x} dx = 1$$ → Integral example
                              • $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$ → Quadratic formula

                              Useful Symbols

                              • \alpha, \beta, \gamma → Greek letters
                              • \frac{a}{b} → Fractions
                              • ^{2} → Superscript (exponents)
                              • _{i} → Subscript
                              • \sqrt{x} → Square root
                              • \sum, \int, \prod → Math symbols

                              Tip: Test your LaTeX at latex4technics.com
