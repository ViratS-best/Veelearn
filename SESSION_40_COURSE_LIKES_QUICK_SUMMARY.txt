================================================================================
                        HOW IT WORKS
================================================================================

USER LIKES A COURSE:
  1. Click ❤️ button in course card
  2. Button sends POST /api/courses/:id/like
  3. Like inserted into course_likes table
  4. like_count incremented in courses table
  5. Button updates to ❤️ with pink background
  6. Like count increases by 1

USER UNLIKES A COURSE:
  1. Click ❤️ button again
  2. Button sends DELETE /api/courses/:id/like
  3. Like deleted from course_likes table
  4. like_count decremented in courses table
  5. Button updates to 🤍 with gray background
  6. Like count decreases by 1

USER SORTS COURSES:
  1. Select sort option from dropdown
  2. Frontend sends GET /api/courses?sort=most_liked
  3. Backend returns courses ordered by selected sort
  4. Frontend re-renders course list in new order

================================================================================
                        API ENDPOINTS
================================================================================

1. POST /api/courses/:id/like
   Authorization: Bearer <token>
   
   Success (200):
   { success: true, message: "Course liked successfully", data: { liked: true } }
   
   Error (400 - already liked):
   { success: false, message: "You have already liked this course" }

2. DELETE /api/courses/:id/like
   Authorization: Bearer <token>
   
   Success (200):
   { success: true, message: "Course unliked successfully", data: { liked: false } }
   
   Error (400 - not liked):
   { success: false, message: "You have not liked this course" }

3. GET /api/courses/:id/likes
   Authorization: Bearer <token>
   
   Success (200):
   { success: true, message: "Like count fetched", data: { like_count: 42 } }

4. GET /api/courses/:id/liked
   Authorization: Bearer <token>
   
   Success (200):
   { success: true, message: "Like status fetched", data: { is_liked: true } }

5. GET /api/courses?sort=most_liked
   Authorization: Bearer <token>
   
   Success (200):
   { success: true, message: "Courses fetched", data: [
       { id: 1, title: "...", like_count: 42, is_liked: true, ... }
   ] }
