================================================================================
                       HOW IT WORKS
================================================================================

TEACHER WORKFLOW:
  1. Opens Dashboard
  2. Sees search bar in "Create Assignment" section
  3. Types course name or description
  4. Dropdown filters in real-time as they type
  5. Selects desired course
  6. Sets optional due date
  7. Clicks "Assign Course"
  8. Assignment created and sent to students

STUDENT WORKFLOW:
  1. Opens Dashboard
  2. Scrolls to "Assignments for Me" section
  3. Sees list of assignments with:
     - Course title
     - Teacher email
     - Due date (or "No deadline")
  4. Clicks "Work on Assignment" to submit work
